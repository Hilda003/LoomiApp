# Loomi (Learning Optimazation Microlearning)

Loomi is an efficient and optimized learning platform to help users learn easier, not harder. By integrating micro-learning based classes, with personalized progress tracking and timely notifications, Loomi keeps learners engaged and on track with their educational goals. So, whether you are a beginner who needs to know about a new topic, or a lifelong learner who wants to optimize your learning habits, Loomi provides the tools you need to gain knowledge. 

# Features
- **Microlearning-Based Courses:** Loomi presents learning content in small, easily absorbed units designed to optimize retention and reduce cognitive load. Each course is split into small lessons that can be completed in just minutes.
- **Progress Tracking:** Visual progress indicators help learners stay motivated and accountable. Users can see how far they have progressed, how many courses are in progress, and which courses have been completed.
- **Smart Notifications & Reminders:** Personalised reminders keep learners engaged without overwhelming them. Notifications can pop up based on their study schedule, so study habits become more consistent and sustainable.
- **Article recommendation:** This feature supports users who want to explore more than just theoretical basics.
